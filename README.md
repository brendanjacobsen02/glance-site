# Glance — landing site

Static marketing + legal site for **Glance** (campus random video chat, 18+).
Plain HTML/CSS, no build step. Served via GitHub Pages.

- `index.html` — landing
- `privacy.html` — privacy policy
- `terms.html` — terms / EULA
- `styles.css` — shared theme (charcoal + amber, matches the app)

Edit and push to `main`; Pages redeploys automatically.
